# App Store Accessibility Evidence

Prepare these declarations before submission, but publish only claims supported by exact-build physical-device evidence. App Store Connect currently has no accessibility declarations configured.

## Apple categories

| Category | Provisional status | Exact evidence required before selecting |
| --- | --- | --- |
| VoiceOver | Unverified | Complete login, bottom navigation, Training, active workout, Daily Tracker, Health & Capacity, DM and Settings using VoiceOver; confirm control names, values, order and modal focus. |
| Voice Control | Unverified | Complete the same core journey using visible control names; confirm duplicate/hidden controls do not block selection. |
| Larger Text (200%+) | Unverified | Run at the largest accessibility text sizes on a small and current large iPhone; confirm no clipped actions, overlapping navigation, hidden picker or unreachable Save/Finish controls. |
| Dark Interface | Likely supported; unverified | Confirm every launch/login/portal/error/offline/modal screen remains dark and legible with Increase Contrast both off and on. |
| Differentiate Without Color Alone | Unverified | Confirm status, readiness, errors, completion and selected states use text/icons in addition to magenta/green/red colour. |
| Sufficient Contrast | Unverified | Measure primary, secondary, disabled and error text against its real background; check charts and workout controls in both normal and increased contrast. |
| Reduced Motion | Unverified | Enable Reduce Motion and confirm splash, transitions, workout progress, charts and loading states remain usable without essential information depending on motion. |
| Captions | Do not claim yet | Inventory every coaching video. Select only if all spoken content has synchronised captions. |
| Audio Descriptions | Do not claim yet | Select only if all essential visual-only video information has an equivalent audio description. |

## Required device record

For each run, record:

- Build: AT CAPACITY 1.0 (8)
- Device model and iOS version
- Tester and date/time
- Accessibility setting/category
- Journey completed
- Pass/fail and issue link
- Retest evidence

## Minimum pass journey

1. Cold launch, splash and login.
2. Dashboard and mobile navigation.
3. Choose a training session, open Session overview, jump to an exercise, log sets, use Apply set 1 to all and finish.
4. Daily Tracker save/edit.
5. Health & Capacity consent, provider cards and empty/error/connected states.
6. DM compose/read and keyboard dismissal.
7. Settings, notification permission explanation, privacy/support links and Delete account confirmation without completing deletion.
8. Offline launch/retry and return from an external provider browser.

If any category is not fully verified, leave that declaration unselected. Accessibility declarations are product claims, not aspirations.
